Saat penyimpanan Android hampir penuh, unduhan, pembaruan aplikasi, dan foto baru bisa terhambat. Namun, menghapus file secara terburu-buru juga bisa menghilangkan data yang belum dicadangkan. Mulailah dengan mencari apa yang paling banyak memakai ruang, amankan file penting, lalu bersihkan yang risikonya paling rendah.

Nama menu dapat berbeda menurut merek ponsel dan versi Android. Jika jalurnya tidak sama, cari “Penyimpanan” atau “Aplikasi” melalui kolom pencarian di Setelan.

## 1. Periksa penggunaan ruang

Buka **Setelan > Penyimpanan** dan lihat kategori terbesar, seperti aplikasi, gambar, video, audio, atau file lain. Jangan langsung menghapus isi kategori “lainnya”: rinciannya bergantung pada perangkat, dan kategori itu belum tentu berisi file yang aman dibuang.

Untuk memeriksa file pribadi, buka aplikasi **Files** atau pengelola file bawaan. Urutkan berdasarkan ukuran jika tersedia. Android juga menyediakan cara melihat dan mencari file melalui aplikasi Files, meski menunya dapat berbeda antarperangkat ([panduan Google](https://support.google.com/android/answer/9110661)). Catat kategori yang paling banyak memakai ruang agar Anda tidak perlu menghapus file secara acak.

## 2. Cadangkan file penting dan periksa salinannya

Sebelum menghapus foto, video, atau dokumen, pastikan ada salinannya di tempat lain yang bisa Anda akses. Salin ke komputer atau penyimpanan eksternal, atau gunakan layanan cloud yang sudah Anda pakai. Setelah itu, buka beberapa file dari lokasi cadangan untuk memastikan salinannya dapat dibaca.

Jika memakai Google Foto, jangan berasumsi semua folder sudah dicadangkan. Buka Google Foto, ketuk foto profil, lalu periksa status pencadangan, akun yang aktif, dan folder perangkat yang ingin disimpan. Langkah pemeriksaannya dijelaskan dalam [panduan pencadangan](https://support.google.com/photos/answer/9343402).

Periksa juga dokumen kerja, rekaman suara, file unduhan, dan data aplikasi yang tidak disinkronkan. Percakapan, permainan, aplikasi catatan, atau aplikasi autentikasi mungkin memerlukan fitur pencadangan atau ekspor di dalam aplikasinya. Jangan menganggap data aplikasi otomatis tersimpan di akun Google.

## 3. Bersihkan unduhan dan media offline

Mulailah dari file yang jelas tidak diperlukan: PDF lama, berkas instalasi yang sudah dipakai, duplikat yang telah diperiksa, rekaman layar yang tidak penting, atau video besar yang bisa diunduh kembali. Cek nama dan isi file sebelum menghapusnya; nama yang tidak dikenal bukan berarti file itu sampah.

Lalu periksa unduhan offline di aplikasi musik, video, peta, atau podcast. Menghapusnya melalui aplikasi asal biasanya lebih aman daripada menghapus folder aplikasi lewat pengelola file. Konten umumnya dapat diunduh lagi selama masih tersedia dan akun atau aksesnya aktif. Google juga menyarankan penghapusan media unduhan melalui aplikasi asalnya ([panduan ruang Android](https://support.google.com/android/answer/15728899)).

Jika memakai Files by Google, tinjau setiap saran di menu **Bersihkan** sebelum menyetujuinya. Kartu “File sampah” menghapus data secara permanen, bukan memindahkannya ke Sampah, dan tidak selalu menampilkan pilihan file satu per satu. Periksa jenis tindakan serta ruang yang akan dibebaskan. Jika ada pilihan file, tinjau file terpilih sebelum mengonfirmasi ([panduan Files by Google](https://support.google.com/files/answer/9713869)).

## 4. Hapus cache bila perlu, bukan data aplikasi

Cache adalah data sementara yang dibuat aplikasi. Menghapusnya biasanya tidak menghapus dokumen pribadi, tetapi aplikasi mungkin lebih lambat saat pertama dibuka kembali karena harus memuat data ulang. Jalurnya umumnya **Setelan > Aplikasi > pilih aplikasi > Penyimpanan dan cache > Hapus cache**, meski nama menu dapat berbeda.

Perhatikan tombol yang dipilih. **Hapus cache** berbeda dari **Hapus penyimpanan** atau **Hapus data**. Menurut [panduan Android](https://support.google.com/android/answer/15728899), menghapus penyimpanan menghapus data aplikasi secara permanen. Anda bisa keluar dari akun atau kehilangan setelan dan data lokal yang belum dicadangkan. Jangan pilih tindakan ini hanya untuk mengosongkan ruang jika belum tahu apa yang disimpan aplikasi.

Cache pun bisa terbentuk lagi, jadi hasilnya tidak selalu bertahan. Prioritaskan aplikasi dengan cache besar hanya jika Anda memahami dampaknya atau sedang mengatasi masalah pada aplikasi tersebut.

## 5. Hapus salinan foto di ponsel setelah verifikasi

Untuk mengosongkan ruang lewat Google Foto, gunakan **Kosongkan ruang di perangkat ini**, bukan menghapus foto dari tampilan aplikasi seperti biasa. Pastikan pencadangan selesai dan akun yang aktif benar. Lalu buka Google Foto di peramban dengan akun tersebut; periksa apakah beberapa foto dan video penting, termasuk dari folder perangkat yang ingin disimpan, dapat dibuka. Fitur ini menghapus salinan di perangkat, sementara salinan yang sudah dicadangkan tetap dapat dilihat di Google Foto saat Anda masuk dan terhubung ke internet ([petunjuk Google Foto](https://support.google.com/photos/answer/6128843)).

Perbedaannya penting: menghapus foto seperti biasa dari aplikasi Google Foto dapat menghapusnya dari Google Foto dan perangkat yang tersinkron. Baca konfirmasi dan pastikan Anda memilih fitur pengosongan ruang sebelum mengetuk tombol akhir. Sesudahnya, sebagian foto mungkin tidak tersedia di galeri bawaan atau saat ponsel offline.

## Kesalahan yang perlu dihindari

- **Menghapus folder yang tidak dikenal.** Folder aplikasi bisa berisi unduhan atau data yang masih dibutuhkan. Jika memungkinkan, hapus isinya melalui aplikasi asal.
- **Mengira semua file sudah dicadangkan.** Periksa akun, status pencadangan, dan folder perangkat. Unggahan bisa tertunda atau tidak mencakup semua folder.
- **Memilih “Hapus data” alih-alih “Hapus cache”.** Kedua tombol punya akibat yang berbeda.
- **Mengosongkan Sampah tanpa memeriksa isinya.** Di Files by Google, file yang dihapus dari Sampah tidak dapat dipulihkan melalui fitur tersebut. Sebagian tindakan pembersihan juga menghapus file secara permanen, sedangkan file yang dipindahkan ke Sampah masih dapat dipulihkan selama tersedia di sana. Periksa tindakan dan menu Sampah sebelum mengonfirmasi ([cara kerja Sampah Files by Google](https://support.google.com/files/answer/10607740)).
- **Mengandalkan satu jenis cadangan untuk semua data.** Foto, dokumen, percakapan, dan data aplikasi mungkin memerlukan cara pencadangan yang berbeda.

## Urutan singkat yang aman

1. Periksa kategori penyimpanan di Setelan.
2. Cadangkan file penting dan pastikan salinannya dapat dibuka.
3. Hapus unduhan, duplikat yang sudah diperiksa, dan media offline yang dapat diambil kembali.
4. Tinjau saran pembersihan; jangan setujui penghapusan permanen tanpa pemeriksaan.
5. Hapus cache hanya bila perlu, bukan data aplikasi.
6. Kosongkan ruang foto setelah pencadangan terverifikasi.

Jika ruang masih sempit, pindahkan file besar ke komputer atau media eksternal, atau hapus aplikasi yang memang tidak digunakan. Hindari aplikasi “pembersih” yang meminta akses luas jika manfaat dan tindakannya tidak jelas. Dahulukan file yang Anda kenali dan bisa diambil kembali; jangan menyentuh data aplikasi yang belum Anda pahami.
