Ponsel hilang atau laptop rusak bisa berarti foto dan dokumen pribadi ikut lenyap jika semua file hanya tersimpan di satu tempat. Aturan backup 3-2-1 membantu Anda menyiapkan salinan yang tetap bisa dipakai saat perangkat atau satu cadangan bermasalah.

## Apa arti aturan backup 3-2-1?

Aturan 3-2-1 berarti menyimpan **tiga salinan data**: satu salinan utama dan dua cadangan. Gunakan **dua jenis media atau penyimpanan yang berbeda**, lalu tempatkan **satu salinan di lokasi lain**, misalnya di luar rumah. Itulah inti panduan yang dijelaskan CISA. ([cisa.gov](https://www.cisa.gov/sites/default/files/publications/data_backup_options.pdf))

Untuk file pribadi, susunannya bisa seperti ini:

1. **Salinan utama:** file di ponsel atau komputer yang Anda gunakan sehari-hari.
2. **Cadangan lokal:** salinan di hard disk atau SSD eksternal.
3. **Cadangan di luar rumah:** salinan di layanan cloud atau perangkat penyimpanan di lokasi lain.

Pastikan setiap kelompok file penting ada di kedua cadangan. Jika file tersebar di ponsel dan komputer, cadangkan keduanya. Jika ponsel hanya menyimpan foto versi hemat ruang, periksa dan unduh file aslinya sebelum menghitungnya sebagai salah satu salinan.

Susunan ini memberi pilihan saat satu salinan tidak tersedia: cadangan lokal masih ada jika ponsel hilang, sementara salinan di luar rumah tidak ikut terdampak jika rumah mengalami kebakaran atau pencurian. Namun, cadangan hanya berguna jika filenya benar-benar bisa dipulihkan.

## Pilih file yang perlu diselamatkan

Mulailah dari data yang sulit atau tidak mungkin dibuat ulang: foto dan video keluarga, dokumen identitas, berkas pajak, dokumen kerja, catatan penting, serta file proyek pribadi. Periksa juga folder Downloads, Desktop, dan folder aplikasi yang mungkin menyimpan dokumen.

Aplikasi biasanya bisa diunduh lagi; foto dan dokumen pribadi belum tentu. Prioritaskan file yang versi terbarunya penting, lalu catat perkiraan ukurannya agar Anda bisa memilih kapasitas penyimpanan yang memadai.

Tentukan juga seberapa banyak perubahan yang rela Anda kehilangan. Jika sering menambah foto, pencadangan mingguan mungkin lebih cocok daripada bulanan. Semakin sering file berubah dan semakin penting isinya, semakin sering cadangan perlu diperbarui.

## Buat cadangan lokal di drive eksternal

Pilih hard disk atau SSD eksternal yang cukup untuk file penting, dengan ruang tambahan bagi salinan berikutnya. Sambungkan drive, lalu salin folder yang sudah dipilih. Di Windows, File History dapat mencadangkan folder pribadi ke drive eksternal atau lokasi jaringan dan menyimpan versi file sebelumnya. Periksa folder yang tercakup karena folder penting di luar pustaka Windows mungkin perlu ditambahkan. Nama menu dan pengaturannya bisa berbeda menurut versi Windows. ([support.microsoft.com](https://support.microsoft.com/en-au/windows/experience/backup-recovery/backup-and-restore-with-file-history))

Jika menyalin secara manual, gunakan susunan folder yang mudah dikenali, seperti `Foto`, `Dokumen`, dan `Proyek`, serta tanggal untuk menandai kumpulan cadangan. Setelah selesai, buka beberapa file langsung dari drive. Indikator penyalinan yang hilang belum membuktikan semua salinan bisa diakses.

Kemudian keluarkan drive dengan aman dan cabut kabelnya. Drive yang terus terhubung dapat ikut terkena masalah pada komputer, termasuk kerusakan listrik atau ransomware. CISA menyarankan cadangan offline dan pengujian pemulihan sebagai perlindungan tambahan terhadap ransomware. ([cisa.gov](https://www.cisa.gov/stopransomware/ransomware-guide))

## Tambahkan salinan di luar rumah

Untuk salinan ketiga, gunakan layanan cloud atau simpan drive cadangan kedua di rumah anggota keluarga tepercaya. Cloud memudahkan pembaruan rutin, tetapi periksa kapasitas, status unggahan, dan folder yang tercakup. Google Photos, misalnya, dapat mencadangkan foto dan video ke akun Google, tetapi dokumen memerlukan cara pencadangan lain. Kapasitas akun digunakan bersama layanan Google lain, dan pencadangan membutuhkan koneksi internet. ([support.google.com](https://support.google.com/photos/answer/6193313?api_client=help_panel&co=GENIE.Platform%3DDesktop))

Perhatikan pula perbedaan sinkronisasi dan cadangan terpisah. Sinkronisasi membuat perubahan di satu perangkat muncul di perangkat lain, sehingga penghapusan yang tidak disengaja bisa ikut terbawa. Pada iCloud Photos, misalnya, perubahan dan penghapusan foto tercermin di perangkat yang menggunakan layanan tersebut. ([support.apple.com](https://support.apple.com/en-us/108782)) Jangan mengandalkan file yang hanya tersinkron sebagai cadangan yang aman dari penghapusan. Simpan salinan terpisah di drive, lalu periksa apakah layanan cloud menyediakan versi lama atau pemulihan file beserta batas waktunya.

Untuk file sensitif, pertimbangkan enkripsi pada drive dan lindungi akun cloud dengan autentikasi kuat. Simpan informasi pemulihan akun di tempat aman, terpisah dari perangkat yang dicadangkan. Enkripsi dapat membatasi akses orang lain, tetapi kata sandi yang terlupa juga bisa menghalangi pemulihan.

## Tetapkan jadwal dan uji pemulihan

Pilih rutinitas yang bisa Anda pertahankan. Misalnya, sambungkan drive setiap akhir pekan untuk memperbarui cadangan lokal, sementara layanan cloud mencadangkan file yang berubah secara otomatis. Setelah memotret acara penting atau menyelesaikan pekerjaan besar, pastikan file sudah masuk ke salinan lain jika Anda tidak ingin menunggu jadwal berikutnya.

Sesekali, pulihkan satu file ke folder sementara. Periksa apakah file terbuka, nama dan isinya benar, serta versinya cukup baru. NIST menekankan pentingnya menguji integritas dan kemampuan pemulihan cadangan. Untuk file pribadi, membuka hasil pemulihan adalah langkah sederhana yang lebih berguna daripada tidak pernah menguji. ([nvlpubs.nist.gov](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-209.pdf))

Gunakan daftar ini untuk mengecek sistem Anda:

- [ ] Saya tahu folder mana yang berisi file penting.
- [ ] Ada satu salinan utama dan dua cadangan.
- [ ] Salinan tidak semuanya bergantung pada perangkat atau lokasi yang sama.
- [ ] Drive eksternal dicabut setelah pencadangan.
- [ ] Saya tahu cara masuk ke akun cloud dan memulihkan file.
- [ ] Saya pernah membuka atau memulihkan beberapa file cadangan.

## Kesalahan yang membuat cadangan kurang berguna

**Semua salinan berada di satu tempat.** Tiga drive di meja yang sama tetap bisa hilang bersamaan akibat pencurian, kebakaran, atau kerusakan lain. Simpan satu salinan di luar lokasi utama.

**Sinkronisasi dianggap cadangan.** Perubahan atau penghapusan yang keliru dapat ikut tersinkron. Siapkan salinan terpisah yang bisa dipulihkan.

**Hasil pencadangan tidak pernah diperiksa.** Drive bisa rusak, unggahan bisa gagal, atau folder penting terlewat. Buka beberapa file dan uji pemulihan secara berkala.

**Cadangan tidak diperbarui atau drive selalu terpasang.** Cadangan lama tidak memuat perubahan terbaru, sedangkan drive yang terus terhubung lebih mudah ikut terdampak masalah pada komputer. Perbarui sesuai jadwal dan cabut drive setelah selesai.

## Mulai dengan sistem yang realistis

Anda tidak perlu langsung membuat jadwal rumit atau membeli banyak perangkat. Kumpulkan file yang paling sulit diganti, salin ke drive eksternal, lalu buat satu salinan di luar rumah melalui cloud atau media kedua. Perbarui sesuai perubahan file dan sesekali uji pemulihannya.

Backup 3-2-1 bukan jaminan mutlak. Namun, sistem sederhana yang rutin diperbarui dan bisa dipulihkan membuat hilangnya satu perangkat atau satu salinan tidak langsung berarti hilangnya semua file.
